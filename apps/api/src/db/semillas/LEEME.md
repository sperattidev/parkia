# Datos de demostración

`firmat-cuadras.json`: cuadras de dos zonas de demostración de Firmat (Santa Fe).

- **Geometría y nombres de calles:** © colaboradores de OpenStreetMap, bajo licencia
  [ODbL](https://opendatacommons.org/licenses/odbl/). Se descargaron con Overpass, se cortaron en
  cada intersección y se agruparon por manzana con PostGIS (`ST_Node` + `ST_Polygonize`).
- **Alturas, capacidad y lugares numerados:** valores de demostración. La numeración real y las
  cuadras incluidas las define el municipio por ordenanza.
